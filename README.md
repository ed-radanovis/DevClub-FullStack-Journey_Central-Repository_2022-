> ### 📚 About the course
>
> **Institution :** DevClub  
> **Format :** Practical Online Course
> **Duration :** 14 weeks ( 206 hours total )
> **Certificate :** Verified Certificate available  
> **Difficulty :** Introductory to the professional
> **Languages & Frameworks :** HTML, CSS, JavaScript, React, Node.js, SQL
> **Lead Instructor :** Rodolfo Mori
> **Methodology :** focused on `real projects` , with live mentoring, technical support, and an active community, ensuring that the student graduates prepared for the demands of the job market.

<br>

> ### 🎯 Course Objectives
>
> Full Stack training aims to empower students to build complete web applications, mastering both front-end and back-end development. Its scope includes practical application for creating a solid portfolio.
>
> 📊 Key Learning Outcomes :
>
> > ✔️ &nbsp; Build modern and responsive interfaces with React.  
> > ✔️ &nbsp; Develop robust and secure APIs with Node.js.  
> > ✔️ &nbsp; Model and interact with relational databases.  
> > ✔️ &nbsp; Version control and teamwork with Git.
> > ✔️ &nbsp; Publish projects to production.

### 📖 Detailed Course Curriculum (by Module)

The curriculum is structured into 10 modules to progressively build the foundations of a full-stack developer. Each module builds upon prior knowledge, combining practical exercises with real-world projects to ensure comprehensive skill development.

| Module |         Main Topic         | Key Concepts                                                                                      | Technologies & Projects                                                                                     |
| :----: | :------------------------: | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **1**  |    **Web Fundamentals**    | HTML structure, CSS styling, DOM manipulation, Responsive design                                  | HTML, CSS, JavaScript<br>• Landing pages (Figma projects)<br>• CSS Challenges (1-3)                         |
| **2**  |      **Advanced CSS**      | Flexbox, CSS Grid, Modern layouts, Advanced styling techniques                                    | CSS<br>• Flexbox projects<br>• Grid layout examples (1-4)                                                   |
| **3**  |    **JavaScript Core**     | Variables, Functions, Arrays, Objects, DOM Events, ES6+ features                                  | JavaScript<br>• DOM manipulation exercises<br>• Array methods (map, filter, reduce)<br>• Calculator project |
| **4**  |  **Advanced JavaScript**   | API concepts, REST/RESTful, Modules, This keyword, Error handling, Promises, Async/Await, Classes | JavaScript, Node.js<br>• Module examples<br>• Promise/Async exercises<br>• Class implementation             |
| **5**  |  **Backend with Node.js**  | Node.js environment, HTTP servers, Express.js, Routing, Middleware, File system                   | Node.js, Express<br>• First Node project<br>• Second Node project<br>• Basic server implementations         |
| **6**  | **Git & Version Control**  | Repository management, Cloning, Committing, Pushing, Branching                                    | Git, GitHub<br>• Repository examples<br>• Git workflow exercises                                            |
| **7**  |  **Frontend with React**   | Components, State, Props, Hooks, JSX, Component lifecycle                                         | React<br>• First React project (frontend)<br>• Component-based applications                                 |
| **8**  | **Full Stack Integration** | REST APIs, Database connectivity, Frontend-Backend communication, Authentication                  | React, Node.js, Express<br>• First React project (full stack)<br>• Backend-frontend integration             |
| **9**  |       **Databases**        | SQL concepts, Database modeling, CRUD operations, Data relationships                              | SQL (PostgreSQL/MongoDB)<br>• Database design concepts                                                      |
| **10** |    **Capstone Project**    | Real-world application, Full stack development, Deployment, Project management                    | Full Stack Technologies<br>• **Fullstack Burgershop** (Complete restaurant management system)               |

### 🧠 Skills Developed

Throughout the course, students acquire both technical and problem-solving skills:

- **Technical Skills:** Developing interfaces with React, creating RESTful APIs with Node.js and Express, modeling and querying SQL databases, version control with Git.
- **Problem Solving:** Debugging full-stack applications, logical thinking to integrate front-end and back-end, reading documentation.
- **Soft Skills & Methodology:** Project-based learning, participation in an active community, peer support, preparation for real selection processes.

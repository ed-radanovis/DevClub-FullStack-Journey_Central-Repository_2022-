### 📖 Detailed Course Curriculum (by Module)

The curriculum is structured into 10 modules to progressively build the foundations of a full-stack developer. Each module builds upon prior knowledge, combining practical exercises with real-world projects to ensure comprehensive skill development.

| Module |         Main Topic          | Key Concepts                                                                                                           |
| :----: | :-------------------------: | ---------------------------------------------------------------------------------------------------------------------- |
| **1**  |    **HTML Fundamentals**    | HTML structure, CSS styling, DOM manipulation, Responsive design                                                       |
| **2**  |  **CSS Styling & Layouts**  | Flexbox, CSS Grid, Modern layouts, Advanced styling techniques                                                         |
| **3**  |  **Version Control (Git)**  | Repository management, Cloning, Committing, Pushing, Branching                                                         |
| **4**  | **JavaScript Fundamentals** | Variables, Functions, Arrays, Objects, DOM Events, ES6+ features                                                       |
| **5**  |     **Node.js Backend**     | Node.js environment, HTTP servers, Express.js, Routing, Middleware, File system                                        |
| **6**  |   **Advanced JavaScript**   | API concepts, REST/RESTful, Modules, This keyword, Error handling, Promises, Async/Await, Classes                      |
| **7**  |  **CSS Advanced Layouts**   | Advanced Flexbox, CSS Grid systems, Responsive design patterns                                                         |
| **8**  |     **React Frontend**      | Components, State, Props, Hooks, JSX, Component lifecycle, Router                                                      |
| **9**  | **Full Stack Integration**  | REST APIs, Frontend-Backend communication, State management across layers                                              |
| **10** |    **Capstone Project**     | Real-world application, Full stack development, SQL (PostgreSQL/MongoDB), Database design concepts, Project management |

---

### 🧠 Skills Developed

Throughout the course, students acquire both technical and problem-solving skills:

- **Technical Skills:** Developing interfaces with React, creating RESTful APIs with Node.js and Express, modeling and querying SQL databases, version control with Git.
- **Problem Solving:** Debugging full-stack applications, logical thinking to integrate front-end and back-end, reading documentation.
- **Soft Skills & Methodology:** Project-based learning, participation in an active community, peer support, preparation for real selection processes.
